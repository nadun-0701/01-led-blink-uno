# 01 - Arduino LED Blink

This is my first microcontroller project simulated using the Wokwi simulator.

## Components Used
- Arduino Uno
- 1x Red LED
- 1x 220Ω Resistor
- Connecting wires

## How It Works
The Arduino sends a `HIGH` signal (5V) to Digital Pin 13 to turn on the LED, waits for 1 second using `delay(1000)`, and then sends a `LOW` signal (0V) to turn it off.
